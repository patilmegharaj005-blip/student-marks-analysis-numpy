# 📊 Student Marks Analysis using NumPy

## 🚀 Project Overview
This project focuses on analyzing student marks using NumPy. It demonstrates how raw data from a CSV file can be transformed into meaningful insights using numerical operations.

---

## 🔍 Features
- Data loading from CSV file  
- Data preprocessing and cleaning  
- Conversion into NumPy arrays  
- Student-wise and subject-wise analysis  
- Calculation of total, average, max, and min marks  
- Identification of top-performing student 🏆  
- Pass/Fail classification based on average marks  

---

## 🛠️ Tech Stack
- Python  
- NumPy  
- Pandas  

---

## 📊 Key Insights
- Computed overall and subject-wise performance  
- Identified trends in student scores  
- Generated result status (Pass/Fail)  
- Extracted actionable insights from raw data
